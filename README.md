# Recut: AI Showrunner

**Every other tool gives you shots. Recut gives you a series.**

Recut is an AI showrunner for short films and ads: you cast locked character
references, paste a script, and a director agent breaks it into named cuts with
blocking and camera presets. Each cut is generated by a reference-to-video model
with the cast bound by name, so the same characters come back in every shot,
with native audio. Keepers land on a real timeline (trim, split, reorder) and
ffmpeg renders the final film with the clips' own audio beds and voice lines
mixed in.

Built for the Qwen Cloud Global AI Hackathon, Track 2 (AI Showrunner).

## Try it in 60 seconds

- `pnpm install`
- `cp .env.example .env.local` and fill in your DashScope key for live generation
- `pnpm dev` and open http://localhost:4800
- Open **/demo** and pick a film: the guided tour replays a real project through
  the actual product UI, step by step, using pre-generated media (no spend).

## The pipeline

```
Cast          Script              Shots                    Edit
locked refs → director skill  →   reference-to-video   →   timeline + export
(1-5 images)  (named cuts,        (refs bound by name,     (trim, split, reorder,
               blocking, camera)   native audio)            ffmpeg + audio mix)
```

- **Cast**: generate or upload reference images per character, prop, or
  location; crown a winner and lock it. Locked references travel by name
  (`@slug`) into every future shot.
- **Script**: paste a script or premise. The director skill (qwen-max) writes
  named cuts (1A, 2A, 3B) with blocking, acting beats, and camera presets. It
  respects the author: names and style blocks stay verbatim.
- **Shots**: each cut's description plus its locked references go straight to
  wan2.7-r2v (reference-to-video). No keyframe roulette: identity holds through
  every frame, with sound.
- **Edit**: keepers form a real timeline. Drag-edge trims, split at playhead,
  media panel, undo. Export renders with ffmpeg: trims, order, per-clip audio
  beds, voice lines mixed over.

## Models (Alibaba Cloud Model Studio / DashScope, ap-southeast-1)

| Role | Model |
|---|---|
| Director / planning | qwen-max |
| Cast image generation + edit | qwen-image-plus / qwen-image-edit |
| Continuity judge | qwen3-vl-plus |
| Video generation (reference-to-video) | wan2.7-r2v |
| Image-to-video (legacy path) | wan2.6-i2v |
| Dialogue TTS | qwen3-tts-flash |

Model ids live only in `manifests/` (enforced by a guard test). Prompts are
compiled from typed state, never concatenated in components.

## Spend safety

Live mode requires `RECUT_BUDGET_USD`; the submitter refuses any job that would
cross the cap and every dollar is tracked in a persisted ledger, surfaced in
the app header.
