# Music beds

Drop short, loopable, royalty-free tracks here named by style, e.g.:

    assets/music/noir.mp3
    assets/music/anime.mp3
    assets/music/cinematic.mp3
    assets/music/storybook.mp3
    assets/music/claymation.mp3
    assets/music/pixar.mp3

The render auto-picks `{style}.{mp3,wav,m4a,ogg}` and ducks it ~-16 dB under the
voiceover. If no file is present, the film ships with no bed (we deliberately do NOT
synthesize a tone — silence under dialogue beats a synthetic hum).

Good free sources: Pixabay Music, Free Music Archive (CC), Kevin MacLeod (incompetech).
